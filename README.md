## 👁️ // OVERVIEW

**ENCRYPT // Ars Cryptographica** is an interactive, terminal-driven cryptographic learning sanctuary. Designed under the aesthetics of **Cryptographic Brutalism**, it pairs conversational guidance with real, zero-compromise WebCrypto API operations. 

Step inside to decode, inspect, and master the mathematical foundations that protect the modern digital dark.

---

## ⚡ // ARCHITECTURAL FEATURES

* **`[ 01 ]` Terminal Interface**  
  Conversational Mentor guide equipped with real-time character typing engines, code snippet breakdown boxes, and step-by-step interactive response choices.

* **`[ 02 ]` Audio Symmetry**  
  - **Initialization (Encryption)**: Ascending frequency sub-bass sweep & white noise frequency filter upon entering the crypt.
  - **De-initialization (Decryption)**: Reversed audio breakdown sweep paired with a white rotating oculus sigil upon terminating the session.

* **`[ 03 ]` Occult Sigil Oculus**  
  A custom mathematical SVG Reticle & Rune Ring inspired by historical ciphers and precision reticles.

* **`[ 04 ]` Secret Command Matrix**  
  Press <kbd>CTRL</kbd> + <kbd>SHIFT</kbd> + <kbd>K</kbd> anywhere inside the terminal to trigger the secret command bar, enabling instant jumping across any curriculum module.
